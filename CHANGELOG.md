# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-03-17

### Added

- Initial Python implementation using only the standard library
- Random inbox generation on existing SkyMail domains
- Message listing and long-poll waiting endpoints
- Example script for waiting on verification emails
- Browser-like request headers for better Cloudflare compatibility
- Bilingual GitHub-ready documentation

### Notes

- This release is intended as the first public version of the repository.
